# 쏙메모 다운로드

카톡 등 메신저에서 받은 메시지·사진을 **공유 → 쏙메모**로 폴더별 메모에 바로 붙여 두는 앱입니다.

## 최신 버전: 1.0.9

**[ssokmemo-1.0.9.apk 내려받기](https://github.com/LeeJongYoun1/memoAppDownload/raw/main/ssokmemo-1.0.9.apk)** (모든 휴대폰용, 약 33MB)

**바뀐 점**
- **빠른 메모**: 어느 화면에서든 화면 위를 쓸어내려 **쏙메모** 타일을 누르면 작은 메모 창이 떠서 바로 새 메모를 저장합니다.
- 메모 창의 `붙여넣기`로 복사해 둔 내용을 한 번에 넣을 수 있습니다.
- `저장 위치`를 눌러 폴더를 고를 수 있고, 마지막으로 고른 폴더를 기억합니다.

## 빠른 메모 켜기
1. 쏙메모 첫 화면 오른쪽 위 ⋮ → **빠른 메모 켜기**를 누릅니다.
2. "타일 추가" 확인창이 뜨면 **추가**를 누릅니다.
   - 확인창이 안 뜨는 휴대폰(안드로이드 12 이하)은 화면 위에서 아래로 두 번 쓸어내림 → 연필(편집) 버튼 → **쏙메모** 타일을 위로 끌어다 놓습니다.
3. 이제 어느 앱에서든 화면 위를 쓸어내리고 **쏙메모** 타일을 누르면 메모 창이 뜹니다.

## 설치 방법
1. 위 링크를 눌러 APK 파일을 내려받습니다. (카톡에서 링크를 열었다면 ⋮ → **다른 브라우저로 열기**)
2. 내려받은 파일을 누릅니다.
3. "출처를 알 수 없는 앱" 안내가 나오면 **설정 → 이 출처 허용**을 켭니다 (Chrome 또는 내 파일 앱).
4. Play 프로텍트 경고가 뜨면 **세부정보 → 무시하고 설치**를 누릅니다.

## 업데이트
- 예전 버전(1.0.1, 1.0.2)을 쓰고 있어도 위 파일을 설치하면 그대로 업데이트되고 메모는 남습니다.
- 1.0.3부터는 파일이 하나뿐입니다. (휴대폰 종류별로 나누지 않습니다)
- 업데이트 전에 앱의 ⋮ → **백업하기**로 백업해 두면 더 안전합니다.
