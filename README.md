# 쏙메모 다운로드

카톡 등 메신저에서 받은 메시지·사진을 **공유 → 쏙메모**로 폴더별 메모에 바로 붙여 두는 앱입니다.

## 최신 버전: 1.0.5

**[ssokmemo-1.0.5.apk 내려받기](https://github.com/LeeJongYoun1/memoAppDownload/raw/main/ssokmemo-1.0.5.apk)** (모든 휴대폰용, 약 52MB)

**바뀐 점**
- 보안 강화: 다른 앱이 공유 기능을 악용하지 못하도록 막았습니다.
- 아주 긴 글이나 사진 수십 장을 공유해도 앱이 멈추지 않도록 한도를 두었습니다.
- 백업 후 "백업 파일은 암호화되지 않아요" 안내를 보여 줍니다.

## 설치 방법
1. 위 링크를 눌러 APK 파일을 내려받습니다. (카톡에서 링크를 열었다면 ⋮ → **다른 브라우저로 열기**)
2. 내려받은 파일을 누릅니다.
3. "출처를 알 수 없는 앱" 안내가 나오면 **설정 → 이 출처 허용**을 켭니다 (Chrome 또는 내 파일 앱).
4. Play 프로텍트 경고가 뜨면 **세부정보 → 무시하고 설치**를 누릅니다.

## 업데이트
- 예전 버전(1.0.1, 1.0.2)을 쓰고 있어도 위 파일을 설치하면 그대로 업데이트되고 메모는 남습니다.
- 1.0.3부터는 파일이 하나뿐입니다. (휴대폰 종류별로 나누지 않습니다)
- 업데이트 전에 앱의 ⋮ → **백업하기**로 백업해 두면 더 안전합니다.
